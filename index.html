Projects

Real Estate House Price Prediction

Python Scikit-learn XGBoost LightGBM CatBoost

Predicted home sale prices from 81 features of the Kaggle housing dataset. Handled missing values and outliers, engineered features, used recursive feature elimination, and tuned models with grid search. The boosting models reached R² = 0.90 on test data, with CatBoost achieving the lowest error.

Predictive Insights into Hotel Reservations

R Classification KNN LDA Logistic Regression

Predicted whether hotel bookings would be cancelled using 36,275 reservations. After exploratory analysis and feature selection, I compared logistic regression, LDA, KNN and Naive Bayes. KNN performed best, with 84.65% accuracy, 79.43% precision and a 75.68% F1-score.

Infectious Disease Trends and Google Search Analysis

R arules Caret XGBoost Neural Networks

Analyzed about 37,000 weekly disease records across 48 US states (2015–2017), linking case counts to Google search trends, travel and demographics. The work covered visualization, yearly aggregation, self-organizing maps, Apriori and ECLAT association rules (up to 96% confidence), and classification with decision trees, gradient boosting, XGBoost, logistic regression and neural networks, evaluated on precision, recall, F1 and AUC.

Fast Food Nutrition Clustering

R tidyverse ggplot2 K-Means Random Forest

Explored nutrition data for menu items across fast food chains, comparing trans fat, cholesterol and total fat by restaurant and by bacon items using ggplot2. Clustered items with k-means, then trained a random forest with 10-fold cross-validation that predicted cluster membership with 95.3% accuracy.

Uber Data Analysis

Python Pandas Seaborn LightGBM XGBoost

Analyzed Uber ride data to find patterns in trip purpose, pickup and drop-off locations, and time of day, then predicted trip distance. Cleaned the data, treated outliers and added time-based features, then compared regression models from linear regression to ensembles. LightGBM, Linear SVR and KNN performed best.

Gold Price Prediction

Python Scikit-learn Random Forest SVR KNN

Forecast gold prices (GLD) from 2,290 days of market data, using the S&P 500, oil, silver and the EUR/USD rate as predictors. Covered data cleaning, correlation analysis and visualization, then compared random forest, decision tree, support vector, linear and KNN regression.

Search Engine with Web Scraping

Python Web Scraping NLP TF-IDF Cosine Similarity

Built a search engine for the University of Memphis website. It crawls up to 10,000 pages, then cleans, tokenizes and stems the text, removes stop words, and ranks pages by TF-IDF cosine similarity. Evaluated it on 10 test queries using precision, recall and F1-score.
